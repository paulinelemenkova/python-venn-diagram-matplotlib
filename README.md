# Venn Diagrams with Python and Matplotlib

Python script drawing Venn diagrams with the matplotlib-venn library. Reusable scientific-plotting example.

## Scripts

- `venn_diagram.py`

## Requirements

Python 3 with `matplotlib`, `matplotlib-venn`.

```
pip install matplotlib matplotlib-venn
```
